💡 핵심 개념 정의

🎯
Naked = 입질 감지 방식

인디케이터 없이 라인 장력과 리더 각도로 입질을 감지합니다. 송어가 흡입하는 순간 라인에 전달되는 미세한 무게 변화를 느끼는 감각 낚시입니다.

📏
롱리더 = 경계심 완화 + 자연스러운 스위밍

9~15ft의 긴 플루오로카본 리더가 라인과 플라이 사이의 완충 역할을 합니다. 플라이가 자연스럽게 유영하도록 유도합니다.

⚓
바저팁 / 밋지팁 (Buzzer Tip / Midge Tip) = 각도 안정화

플로팅 라인 앞부분에 연결하는 짧은 싱킹 팁(4~6ft)입니다. 깊이 확보보다 리더 시작점을 수면 아래로 내려 안정화하는 것이 핵심. 리더가 수면에서 직접 꺾이는 것을 방지하고 플라이 상승을 억제합니다.

🟢
Biostrike 다분할 인디케이터

리더에 소량을 2~3개 분산 배치. 완전 플로팅 라인 전용으로 사용합니다. 입질 시 사선으로 쭉~ 빨려 들어가는 다이나믹한 시각적 반응이 특징입니다.

💬 핵심 포인트

롱리더의 장점과 Naked 운영의 안정성을 가장 균형 있게 살리는 구조입니다.

C. 풀싱킹 라인 + 숏리더
역할: 중하층~바닥 공략 / 빠른 수심 도달 / 입질 직결감 강화
중하층·바닥 특화
장점 / 단점
수심 도달 빠름 — 효율적
반복성 좋음, 입질 직결감 강함
중하층~바닥 체류 능력 우수
인디케이터 장착 불가 (풀싱킹 라인 특성상)
롱리더 피네스 운용 불가
바텀 걸림 위험
자연스러운 프리젠테이션 감소
⚠️ 주의 사항

풀싱킹 라인은 라인 전체가 수중에 가라앉는 구조이므로, 인디케이터 장착이 불가합니다. 입질은 라인 장력과 로드 팁의 변화로 감지합니다.

⚙️ 추천 라인 조합
DI3 class / Parabolic / Multi-density
SA Sonar Stillwater Parabolic Sink WF5S
DI3 class Full Sinking

① 표층 / 상층 Floating + Long Leader

완전 플로팅 라인 + 긴 플루오로카본 리더. 인디케이터(Biostrike) 호환 가능.

예: RIO Elite Gold Classic WF5F / Rio Elite Technical Trout WF4F
② 상층~중층 초입 ⭐ Naked 핵심 Buzzer/Midge Tip + Long Leader

리더 시작점을 수면 아래로 고정. 각도 안정화 + 플라이 감승 억제. Naked의 핵심 구조.

예: Snowbee XS-Plus Buzzer 1 / Snowbee Spectre Pro 6ft Sink Tip
③ 중층 초입~중층 탐색 Hover / Slow Sink

호버 라인 (1.0ips). 느린 리트리브 시 수층을 유지하며 전층을 천천히 탐색하는 성향.

예: SA Sonar Stillwater Hover WF5-H
④ 전층 탐색~중층/중하층 Intermediate

중간 침강 속도. 전층을 두루 탐색하기에 최적. 느린 리트리브 시 전층을 고르게 통과하며 탐색.

예: RIO Sub Surface CamoLux WF5I
⑤ 바텀 DI5 Full Sinking

바닥 공략 전용. 빠른 침강으로 깊은 수심층 즉시 도달.

예: DI5 class Full Sinking
